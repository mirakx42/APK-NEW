=========================================================
  MirakX Store - APK Android (avec synchronisation cloud)
=========================================================

COMPILER L'APK (GitHub fait le travail, gratuit)
  1. Depot GitHub (ex. MirakX-android) > Add file > Upload files
  2. Glissez le CONTENU de ce dossier (.github, app, build.gradle,
     settings.gradle, gradle.properties), pas le dossier parent.
     Verifiez que le dossier ".github" apparait dans la liste.
  3. Commit changes > onglet Actions : la compilation demarre seule
     (5 a 8 minutes).
  4. Pastille verte > cliquez la tache > Artifacts > MirakX-Store-APK
     > telechargez le zip > dedans : MirakX-Store.apk
  5. Installez l'apk sur le telephone (autoriser les sources inconnues).

METTRE A JOUR PLUS TARD
  Remplacez le fichier app/src/main/assets/index.html dans le depot :
  la compilation repart et produit un nouvel APK.

SYNCHRONISATION ENTRE TELEPHONES (menu : Synchronisation)
  Une seule fois : creer une base gratuite Firebase (Realtime Database),
  coller ces regles dans l'onglet "Regles" puis "Publier" :

{
  "rules": {
    "mirakx": {
      "$id": {
        ".read": true,
        ".write": "!data.exists() || !newData.exists() || newData.child('rev').val() === data.child('rev').val() + 1"
      }
    }
  }
}

  Les etapes detaillees sont aussi affichees dans l'application.
  Premier telephone : coller l'adresse de la base > "Creer la synchronisation".
  Autres telephones : "Rejoindre" avec la cle affichee sur le premier.
  Les donnees sont chiffrees avant l'envoi. Ne partagez la cle qu'avec
  vos propres appareils.
